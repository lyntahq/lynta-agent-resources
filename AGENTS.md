# Lynta public information for agents

Lynta is realtime infrastructure for applications and AI agent workflows. Its public product model has three primitives:

- **State** syncs backend-owned changes to connected clients.
- **Channels** carry ephemeral events between connected participants.
- **Tasks** make live work and participation visible.

The customer's backend remains authoritative and runs any AI agents. This site publishes product descriptions and pricing; its previews are illustrative, not implementation contracts.

The public site does not publish a customer-facing product API reference, product OpenAPI contract, SDK package, authentication flow, sandbox, or product-action MCP server. Its [OpenAPI document](https://lyntahq.com/openapi.json) describes read-only keyword search over public pages only. The read-only [MCP server](https://lyntahq.com/mcp) provides tools and Markdown resources for published website pages and cannot operate the product. Do not invent product endpoints, package names, credentials, or runnable code. Direct integration questions to the [early access form](https://tally.so/r/jaOogE).

For structured product details, read [llms.txt](https://lyntahq.com/llms.txt), the [agent view](https://lyntahq.com/?mode=agent), and the [developer resources](https://lyntahq.com/developers).
